# 이예닮 개발 포트폴리오

제품 개발, 데이터와 자동화, 서비스 운영 경험을 소개하는 개발자 전용 포트폴리오입니다.

## 구성

- `index.html`: 소개, 주요 프로젝트 5개, 경력, 개발 역량, 연락처
- `assets/css/style.css`: 반응형 레이아웃, 프로젝트 그래픽 및 모달 스타일
- `assets/js/main.js`: 프로젝트 모달 열기·닫기 및 배경 스크롤 제어
- `assets/img/favicon.svg`: 사이트 아이콘
- `inner-page.html`, `portfolio-details.html`: 기존 주소에서 새 프로젝트 영역으로 이동

HTML/CSS, 인라인 SVG 및 기본 JavaScript를 사용하며, 빌드나 패키지 설치 없이 동작합니다. 카드 전체를 클릭하거나 키보드로 선택하면 브라우저 기본 `dialog` 모달에 상세 내용을 표시합니다. 닫기 버튼, Escape 키, 배경 클릭으로 닫을 수 있습니다.

## 미리보기와 배포

`index.html`을 브라우저에서 직접 열거나 정적 HTTP 서버로 저장소 루트를 제공하면 됩니다. GitHub Pages에서도 루트의 `index.html`을 그대로 사용할 수 있습니다. 모든 로컬 리소스 경로는 상대 경로입니다.

## 내용 수정

프로젝트 설명과 경력은 `index.html`에서 수정합니다. 상세 내용은 파일 하단의 `project-*` 템플릿에 있으며, 서비스 링크는 해당 템플릿의 `project-service` 요소에서 수정합니다. BOROA와 영월고향방앗간에는 사용자 제공 URL을 연결했으며, DOOGO PLUS는 프로젝트 중단, OLVIEW는 서비스 준비 중으로 표시합니다. 공개 연락처는 이메일과 GitHub만 사용합니다. 음향 관련 내용은 포함하지 않습니다.

기존 템플릿 리소스는 `assets` 안에 남아 있지만 새 포트폴리오는 이를 참조하지 않습니다. 기존 리소스의 출처는 `Readme.txt`를 참고하세요.

## 확인

`node tests/check-projects.cjs`로 카드와 상세 템플릿 연결, 서비스 URL, 프로젝트 상태를 확인할 수 있습니다. `node --check assets/js/main.js`로 스크립트 구문을 검사합니다.

경력은 기존 포트폴리오 기준 8개 회사·활동으로 구분하며, 각 경력의 담당 프로젝트는 경력 상세 모달에서 확인할 수 있습니다. 기존 DevOps·AI 연구 링크는 연구 기록 섹션에 보존했습니다.

## 모션

메뉴·링크 피드백, 카드 호버·클릭, 스크롤 진입, 모달 열기·닫기 전환을 적용했습니다. 히어로는 빛의 흐름·창문 조명·포인터에 따른 미세한 깊이 효과를 사용하고, 화면 밖에서는 배경 애니메이션을 일시정지합니다. OS의 동작 줄이기 설정에서는 CSS 및 JavaScript 애니메이션을 생략합니다.

`node tests/check-motion.cjs`로 닫기 전환 중 반복 클릭, 스크롤 잠금 해제, Escape·배경 클릭, 동작 줄이기를 검증합니다.

## GitHub 기반 프로젝트 보강

2026-10-17 기준 연결된 계정의 공개·비공개 저장소 50개를 열거하고 주요 문서·구현을 대조했습니다. 주요 프로젝트 5개와 경력 8개를 유지하고 추가 개발 기록 17개를 모달과 함께 정리했습니다. 검토 범위와 근거는 `docs/github-review.md`에 기록했습니다. 빈 저장소와 음향 트랙은 개발 실적으로 추가하지 않았고 비밀값·원본 데이터·내부 URL은 옮기지 않았습니다.

안내 문구와 장식 화살표를 제거했습니다. 도시 건물 뒤에 일반적인 예시 코드가 상승하는 장식을 추가하고, 나머지 섹션에는 낮은 대비의 격자와 빛 효과를 적용했습니다. 배경 코드는 실제 비공개 소스가 아닙니다.

## 현재 구성 변경

소개 직무는 DevOps Engineer입니다. 주요 프로젝트 6개는 동일한 2열 그리드이며 첫 행에 DOOGO PLUS와 이룸스튜디오를 배치했습니다. 이룸스튜디오의 사용자 제공 서비스 URL은 `http://eroom-studio.co.kr/`입니다. 개발 기록은 중복을 제거한 16개이며, 연구 기록 섹션은 삭제했습니다. 프로젝트 이후에는 전체 폭의 격자와 청록·청색 빛 배경을 적용했습니다.

2025년 이후 활동은 회사 대표 경력 대신 프리랜서 개발·운영 활동으로 정리했습니다. 기존 유지관리 PM 이력은 보존하고 저장소에서 확인한 서비스·자동화·연구개발을 보강했습니다. 이룸스튜디오의 전 과정 단독 개발과 현재 배포·서버 관리 역할은 사용자 확인을 반영했습니다.

히어로 진입은 원래 도시 실루엣을 30개 구간으로 나눠 뒤쪽·앞쪽 순서로 세우고, 코드가 올라온 뒤 약 2.5초부터 소개를 표시합니다. 동작 줄이기에서는 즉시 완성된 상태를 표시합니다. 본문은 섹션별 배경 대신 하나의 연속된 배경을 공유하며 경력 첫·마지막 행의 상하 여백을 통일했습니다.

본문의 격자 배경을 제거하고 비정형 SVG 경로 7개와 흐르는 빛, 서로 다른 속도의 경로 이동으로 교차가 달라지는 배경을 적용했습니다. 상단바는 반투명 고정형이며 모바일 앵커 이동도 메뉴 높이를 고려합니다. 히어로 소개는 직무·제목·설명 순서로 천천히 밝아집니다.

소개 타이밍은 마지막 건물 완료 2260ms에 맞췄으며 건물과 동일한 1000ms 지속시간·이징으로 전체 소개가 함께 나타납니다. 본문은 수직 샤프트와 완만한 모서리의 지하 통로, 내부 신호 흐름으로 구성하며 기존 곡선의 흔들림은 제거했습니다.

최종 소개 타이밍은 건물 완성 1초 전인 1260ms 시작, 2260ms 완료입니다. 지하 배경에는 예시 코드가 배선 경로를 따라 놓이고, 런타임·복구 코드가 작은 제어실처럼 표현됩니다. 실제 프로젝트 소스는 배경에 사용하지 않습니다.

상단 메뉴는 Home·Work·Archive·Career·About·Contact로 실제 섹션에 대응합니다. 모바일에서는 메뉴를 두 번째 줄에 배치해 모든 항목을 유지하며, 고정 메뉴의 높이를 앵커 여백에 반영합니다. 역량 3개 항목은 첫 항목까지 동일한 좌우 여백을 사용합니다.
